1.  while writing testing code : 
remember the 3 A's of testing : Arrange, Act, Assert.
Arrange: Set up the necessary preconditions and inputs for the test.
Act: Execute the code being tested with the arranged inputs.
Assert: Verify that the code behaves as expected and produces the desired output.


# Suites and Test Cases
- A **test suite** is a collection of related test cases that are grouped together to test a specific functionality or module of the software. It allows for organized and structured testing, making it easier to manage and maintain tests.
- A **test case** is a single unit of testing that checks a specific aspect of the software's behavior. It consists of a set of inputs, execution conditions, and expected results that define how the software should behave under certain circumstances.
